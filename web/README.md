# Цифровая НИС — Дашборд

Интерактивный React-дашборд для визуализации транзакционного графа
смарт-контрактов «Цифровой НИС».

## Что показывает

- **Форма новой сделки** — прогон полного цикла: эмиссия → блокировка →
  верификация → разблокировка. Обращается к `POST /api/v1/demo/run`.
- **Граф транзакций** — четыре шага с индикацией статуса. Клик по шагу
  открывает инспектор с ГОСТ-хэшами и payload.
- **Инспектор контракта по DealID** — `GET /api/v1/escrow/{dealID}`.
- **Контур безопасности** — счётчики, merkle_root, статус mTLS.

## Стек

- Vite 5 + React 18 + TypeScript
- Tailwind CSS 3
- lucide-react (иконки)

## Запуск

Требуется Node.js 18+.

    npm install
    npm run dev

Dev-сервер поднимется на http://localhost:5173.

Vite проксирует `/api` и `/healthz` на `http://localhost:8080` —
там должен работать узел (`nis-node`). Запусти его в другом терминале:

    cd ..
    ./bin/nis-node.exe -config ./configs/node-smolensk.yaml

## Сборка для продакшена

    npm run build

Статика окажется в `web/dist/`. Её можно раздавать любым
HTTP-сервером (nginx, Caddy). Для Astra Linux SE рекомендуется
отдавать статику через nginx с TLS-терминацией.
